# AI Website Auditor

## Purpose

AI Website Auditor is a full-stack AI-powered web application that analyses websites and provides actionable recommendations for improving SEO, accessibility, performance and user experience.

The system combines deterministic website analysis with Large Language Models to generate understandable reports for both technical and non-technical users.

---

## Objectives

- Build a production-quality portfolio project
- Demonstrate AI integration
- Demonstrate web scraping
- Demonstrate API development
- Demonstrate database design
- Demonstrate report generation
- Demonstrate full-stack development
