# User Stories

## Website Audit

As a user,

I want to submit a website URL,

So that I can receive a website audit.

---

## Report Dashboard

As a user,

I want to see my website scores,

So that I understand what needs improving.

---

## AI Recommendations

As a user,

I want AI to explain technical issues,

So that I know how to fix them.

---

## PDF Export

As a user,

I want to export the audit,

So that I can share it with clients or colleagues.
