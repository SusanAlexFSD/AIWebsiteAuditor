# Functional Requirements

## Must Have

- User can enter a website URL
- System validates URL
- System crawls website
- System runs Lighthouse audit
- System detects broken links
- System analyses metadata
- AI generates recommendations
- User views report dashboard
- User exports PDF report

---

## Should Have

- Screenshot capture
- Multi-page scanning
- Historical reports

---

## Could Have

- Competitor comparison
- AI chat assistant
- Scheduled monitoring
- Email reports
